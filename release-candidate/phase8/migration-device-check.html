保存データ移行を実機確認

このテストの目的

現在のOneDrive／端末版にある自分の保存内容だけを、将来のPages版でも引き続き使えるか確認します。敵データ更新のテストではありません。

本番の保存内容には触れず、次の架空データだけをPages確認版へ移します。

  • 保存キャラクター：2件（架空の保存キャラクターA・B）
  • 保存済み状況：2件
  • 作業中の状況：1件
  • 手動保存した敵：1件
  • 設定：2分類（耐久ライン・配色）
  • 会心補正：1件
  • GitHub PAT：移行しません

イベント・ステージ・配布敵データは増えません。 移行後は、開いた確認版の「計算する状況」に「架空の作業中状況」が直接表示されます。DEF 150,000・軽減30%・自分の属性「超体」を確認してください。

GitHub PATと端末内の未知の保存項目は読み取りも移行もしません。
