## ownerが今回確認する4項目

1. 通常起動時に`敵の会心`だけが見え、3つの設定は閉じていることを確認する。見出しを押すと編集でき、値を設定して閉じても耐久／被ダメージ結果が変わらないことを見る。
2. 上から`DEF設定`の最後に`ダメージ軽減率`、次に`属性・防御設定`、その次に`敵の会心`の順であることを見る。
3. 被ダメージmodeで`架空イベント・森 → 架空ステージ1 → 架空の緑敵`を選ぶ。通常、各必殺、全体攻撃の数値末尾に灰黒いblockがなく、`600,000～1,300,000`等が途中改行されないことを確認する。
4. 通常攻撃と全体攻撃を計算し、被ダメージ側が属性側より広いこと、被ダメージrangeが途中改行されないこと、属性2行が読めること、画面全体が左右へscrollしないことを見る。

異常があれば、PC／Android／iPhone、手順番号、選択した攻撃、画面写真を知らせる。ownerの確認完了まではPhase 9へ進まない。
