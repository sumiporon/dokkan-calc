## ownerが今回確認する項目

1. PCと360～390px程度のスマホで「属性・防御設定」を開き、属性防御Lv／全属性ガード、敵の会心、ATK／DEF補正が自然な4段配置で、横にはみ出さないことを見る。
2. 耐久ラインで、属性selectorのすぐ下に「最終DEF」「軽減率」「全属性ガード」が1行表示されることを確認する。DEF、軽減、ガードを変え、表示と耐久結果が即座に変わることを見る。
3. 被ダメージへ切り替え、結果のすぐ上にも同じ3項目があることを確認する。イベント、敵、攻撃またはカスタム攻撃を選び、入力変更で結果が自動更新されることを見る。
4. 不要な2つの説明文、「保存データ移行」button／案内／件数／確認画面がないことを確認する。
5. 状況cardを2枚以上作り、別々の入力を行って再読込する。Pages候補内では複数cardと入力が残り、個別／一括開閉も従来どおり使えることを確認する。
6. OneDrive旧版を普段の場所から開く必要がある場合は、previewとは独立した旧known-goodとして以前どおり動くことだけを確認する。両者で保存内容が同じになる必要はない。

異常があれば、PC／Android／iPhoneのどれか、上の手順番号、入力値、表示結果、可能なら画面写真を知らせる。ownerの確認完了まではPhase 9へ進まない。
